Featured Platform

SmartCheque Banking Platform
for BFSI

A mobile-first banking infrastructure platform replacing desktop scanners with intelligent, compliant, real-time cheque processing at branch level.

The Problem

Banks were relying on desktop-bound cheque scanners with expensive hardware, high failure rates, and limited real-time visibility. Processing was manual, slow, and error-prone. Clearing cycles were at risk.

The Platform Built

Designed and shipped a mobile-native cheque processing system with an Android application, REST backend, and SQL Server data layer. Replaced scanner dependency entirely. Geo-fencing enforces branch-premise compliance.

Engineering Highlights
  • SOAP → REST API migration for scale and interoperability
  • Real-time cheque detection and auto-cropping pipeline
  • Auto back-image generation that eliminated a manual step
  • MDM-managed deployment across 5,500+ devices
  • Hardware SDK integration (document scanners, robotic arm middleware)
  • Passed CERT-In AppSec audits across all cycles
