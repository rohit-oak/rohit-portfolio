Personal Project

Klaviyo Bundle Tracker: Automated Marketing Creative Intelligence Pipeline

A marketing team needed to audit roughly 120 Klaviyo email flows across USA, UK, and EU stores to catalog which product bundles appeared in live email creatives. Previously this meant manually clicking through every flow and reading bundle names off images by eye. Built a Python pipeline that pulls live, non-draft flows across multiple market accounts, extracts real creative images from the email HTML, and identifies bundle names through a hybrid local OCR and fuzzy-matching engine, writing results idempotently to Google Sheets.

Problem

Cataloging bundle appearances across ~120 live email flows in three markets was a fully manual, eyes-on-image process with no audit trail.

Solution

Automated flow discovery, image extraction, and a hybrid OCR plus token-set fuzzy matcher with confidence-tiered results and human review escalation for ambiguous cases.

Impact

A free, fully local OCR stack chosen over a paid vision API after benchmarking, idempotent Sheets reporting, and 136 tests including real-image integration benchmarks.

Bounded-concurrency API pulls Hybrid OCR (PaddleOCR + Tesseract) Token-set fuzzy matching Confidence-tiered triage Idempotent Sheets writes Benchmark-driven validation
  • Benchmarked three OCR approaches, Tesseract, PaddleOCR, and a hybrid confidence pipeline, against real email images before defaulting to a free, fully local stack over a paid vision API, with the accuracy, cost, and speed trade-offs documented explicitly.
  • Root-caused real bugs through direct inspection of raw API and OCR output rather than guesswork, including an undocumented Klaviyo response shape (flow-action status nested under a definition object) and a Unicode normalization ordering bug affecting accented characters.
  • Built a reproducible benchmark harness against real email images with an explicit expected-vs-actual acceptance table, catching a regression-inducing threshold bug that unit tests alone would have missed.
  • Designed a three-way outcome model, confidently found, confidently no bundle, or flagged for review, to eliminate false-positive review-queue noise from decorative images like logos and social icons.

Personal Project

Shopify Discount Operations Engine

A Python CLI tool for auditing and safely bulk-updating Shopify discount codes through the Admin GraphQL API. The engine discovers all active free-shipping discounts, computes the minimal set of changes needed to enforce a target shipping-destination policy, and applies those changes with dry-run previews, human confirmation gates, retry-safe HTTP transport, and CSV audit reporting. Architected with clean separation of concerns across clients, config, domain models, planning, and execution, with full dependency injection for testability.

Problem

Auditing and bulk-updating active free-shipping discount codes by hand was slow and risked an unsafe, unreviewed change going live.

Solution

A CLI that computes the minimal delta needed to enforce a target policy, then applies it only after a dry-run preview and explicit human confirmation.

Impact

Retry-safe, fault-isolated batch execution with full CSV audit trails and a fully tested, dependency-injected codebase.
